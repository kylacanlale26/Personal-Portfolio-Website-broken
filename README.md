Name: Kyla G. Lacanlale

## Project Description
This project is a my personal portfolio website that introduces myself. It shows a brief description of who I am, my educational background, the skills I continue to develop, my personal hobbies and interests, the career paths that I wish to pursue, and lastly, my contact information. This project aims to provide a simple and organized way for others to learn more about me.

## Features of the Websites
- Personal Profile
- About Me
- Educational Background
- Skills
- Hobbies and Interests
- Career Goals
- Contact Information

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Fonts
- SVG, PNG, and JPG Images
